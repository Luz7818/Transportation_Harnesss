# API 平台化三件套:OpenAPI 导出 + Python SDK(harness-client)+ 接入文档

**目标**:把项目从"工具"升级成"可被任何人 5 分钟接入的平台"——面试叙事的核心增量。所有端点已存在(30+ 个 REST 端点、双鉴权通道),本计划不新增业务端点,只做"平台化外壳"。

---

## 一、OpenAPI 导出

**新文件 `scripts/export_openapi.py`**
- 设置 `AUTH_MODE=login` + `AUTH_TOKEN=dummy` 环境变量 → 导入 `webapp.app` → `app.openapi()` → 写入 `docs/openapi.json`(参数 `--out` 可覆盖)
- 不启动服务器,纯离线导出;产物可直接导入 Postman/Apifox/Swagger UI

**`webapp/app.py` 小改(为 OpenAPI 质量)**
- 为全部路由补 `tags=[...]` 七个分组:auth / metadata / analysis / cases / eval / reports / llm——`/docs` 与 openapi.json 从平铺变分栏(面试演示 /docs 时的直观提升)
- 版本统一:`pyproject.toml` 1.3.0 → 1.5.0(与 `app.version` 对齐,消除双源不一致)

---

## 二、Python SDK(新目录 `sdk/`,独立可安装包,零侵入主项目)

**`sdk/pyproject.toml`**:PyPI 名 `transportation-harness-sdk`,导入名 `harness_client`,hatchling 构建,仅依赖 `httpx>=0.27`,Python ≥3.11,MIT;`[project.scripts]` 提供 CLI `harness-client`

**`sdk/harness_client/`** 四个模块:
- `client.py` — `TransportationHarnessClient(base_url, token=None, username=None, password=None, timeout=10.0, transport=None)`
  - 鉴权:有 token 走 `X-API-Token` 头;给 username/password 则自动调 `/api/auth/login`(httpx.Client 自动管理 Cookie);两者都支持
  - 方法与 30+ 端点一一对应:`health / versions / datasets / segments / analyze / list_cases / get_case / create_case / delete_case / batch_delete_cases / run_eval / evolve / reports / get_report / evolutions / get_evolution / compare`
  - 统一错误:非 2xx 解析 `{"detail": ...}` 抛 `HarnessAPIError(status, detail)`,401 细化为 `HarnessAuthError`
- `models.py` — 轻量 dataclass + `from_dict`:`EvalResult`(含 API 附加的 report_id)、`CaseResult`、`CheckResult`、`CompareResult`;`run_eval/compare` 返回强类型,其余返回 dict(保持薄)
- `errors.py` — 两个异常类
- `cli.py` — `harness-client health|analyze|eval|versions` 子命令(argparse,中文帮助),entry point 让面试官 `pip install` 后直接敲命令看到数据

**构建 artifacts**:`python -m build` 产出 wheel/sdist 到 `sdk/dist/` 并**提交入库**(用户已选此方案);本地 `pip install ./sdk` 即装;PyPI 实际上传留作用户后续操作(需其账号)

## 三、接入文档

**新文件 `docs/INTEGRATION.md`(《5 分钟接入指南》,面试演示的入口页)**
1. 获取服务地址与令牌(`AUTH_TOKEN` 环境变量 / 登录会话,两种通道)
2. 30 秒验证:cURL 三行(打 health / versions)
3. Python SDK:安装(`pip install ./sdk`)+ 三个核心场景完整代码(发起分析 / 跑评测取报告 / 一键自进化 + 版本对比)
4. 原生 httpx/requests 备选写法(不用 SDK 也能接)
5. 错误码表(400/401/404/409/429/500)+ 限流说明(登录锁定已内置;通用限流由网关层负责)
6. OpenAPI 导入 Postman/Apifox 指引 + 多环境地址表(本地 8765 / ECS 公网 47.114.37.174:8765 / 未来 https 域名)

## 明确不做(范围外,面试追问时的话术已备)

- 通用接口限流(登录锁定已内置;平台化语境下限流属网关层,文档中注明——auth.py 注释也是此口径)
- 全端点响应 Pydantic 模型化(大重构,对三件套目标边际收益低)
- PyPI 实际上传(需您的账号;wheel/sdist 已就绪随时可发)

**工作量**:约 2~3 小时纯实现 + 验证。所有改动不触碰 harness 评测核心与前端,回归风险低。
